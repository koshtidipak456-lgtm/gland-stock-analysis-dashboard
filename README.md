# AI-Powered Stock Market Analysis Dashboard

This project is a professional financial analytics dashboard developed using Python for stock market analysis, forecasting, and algorithmic trading.

## Features
- Stock Price Analysis
- Candlestick Charts
- Moving Average Indicators
- ARIMA Forecasting
- Trading Signals
- Backtesting System
- KPI Metrics
- Volatility Analysis
- Interactive Plotly Dashboard
- Monthly & Yearly Return Analysis

## Technologies Used
- Python
- Pandas
- NumPy
- Plotly
- Statsmodels
- Scikit-learn
- Matplotlib
